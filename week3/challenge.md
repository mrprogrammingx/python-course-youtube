# Week 3 challenge

Make a `week-3` folder inside `python-course`, using only the terminal.

## Steps
1. Open a **new** terminal window.
2. Go to your home folder:
   ```
   cd ~
   ```
3. Go into `python-course`:
   ```
   cd python-course
   ```
   (If it says the folder does not exist, make it first with `mkdir python-course`, then run `cd python-course`.)
4. Make the folder:
   ```
   mkdir week-3
   ```
5. Check it worked:
   ```
   ls
   ```
   You should see `week-3` in the list.

## Same steps, all in one place
```
cd ~
cd python-course
mkdir week-3
ls
```

## Tips
- Use a dash in `week-3`, not a space.
- Press **Tab** after typing `cd pyth` and the terminal finishes `python-course` for you.
- Made a typo? Press the **Up arrow** to bring the last command back, fix it, and press Enter.
