# Week 3: Install Python and use the terminal

Episode 3 of the free **Python Masterclass: Zero to Professional**.
Video: *Python for Beginners #3: Install Python & Use the Terminal* → [VIDEO LINK]

## What this episode covers
- Open a terminal on Windows, Mac and Linux
- Install Python on all three systems
- Check it works: `python --version` (Windows) or `python3 --version` (Mac, Linux)
- Fix the three most common errors
- Four terminal commands: `pwd`, `ls`, `cd`, `mkdir` (plus Tab and the Up arrow)
- Your first lines inside Python, and `exit()` to leave

## Before you start
This course needs **Python 3.12 or newer**. Your number may differ from the one in the video, and that is fine.

## Your own `week-3` folder
The challenge makes a folder called `week-3` inside `python-course` on **your** computer. It starts empty. From Episode 4 on, you will keep each week's files in a folder like it. This repository folder holds the notes, not your code.
